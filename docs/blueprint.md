# Links MAP：プロジェクト設計指針（Blueprint）

## 1. プロジェクト概要
本作は、ユーザーが複数の「作品世界（World）」を管理し、その中の実体と関係性をグラフ構造で可視化・編集する創作支援エディタである。「点（Entity）」と「線（Connection）」の組み合わせにより、複雑な物語の相関図を動的に構築する。

## 2. コア思想：Everything is a Connection
情報の重複を排除し、かつ柔軟な拡張性を持たせるため、以下の設計思想を徹底する。

- **Entities（実体）の極小化**: Entityテーブルは名前と識別子のみを持つ。その他の属性は持たせない。
- **Connections（関係性）への集約**: あらゆる属性、エピソード、因縁は、すべてConnectionテーブルに集約する。
- **自己参照プロフィール (The Heart of the System)**:
  - `from_id` と `to_id` が同一のConnectionを「詳細・プロフィール」として定義する。
  - 「自分自身との関係」が「自分自身の説明」となるデータモデルを実現する。

## 3. 実装ガイドライン（Frontend / UI）

### A. コード提示のルール（AIエージェント・ユーザー共通）
ソースコードを提示する際は、コードブロックの先頭に必ず以下の情報を記述すること。
1. **File Path**: ファイルのフルパス
2. **File Name**: ファイル名
3. **Overview**: 役割と変更内容の概要

### B. コードの秩序と保守性（100点への道）
- **絶対パスインポート**: `import ... from '@/components/...'` 形式を採用し、相対パス地獄（../../）を回避する。
- **定数の一元管理**: ルーティングパス、UIテキスト、マジックナンバーは `src/constants/` で管理する。
- **Barrel File (index.ts)**: 各ディレクトリに配置し、外部へのインポート文をクリーンに保つ。
- **型定義の自動生成**: Supabase CLI を活用し、DBスキーマとフロントエンドの型を同期させる。
- **テストとドキュメント**: 複雑なロジックには `vitest` によるテストと TSDoc 形式のコメントを付与する。

### C. データの描画ロジック（React Flow）
`connection_tags.graph_type` に応じて振る舞いを出し分ける。
- **'self'**: グラフ上の線としては描画せず、詳細パネルのエディタ用データとして扱う。
- **'edge'**: 標準的な接続線として描画。
- **'box'**: `parentNode` として設定し、包含関係（グループ化）を視覚化。
- **'flow'**: 時間軸に沿った連続的な矢印。

### D. ルーティングと防御
`react-router-dom` の Layout 構文を活用。
- **PublicRoute**: 非ログイン時のみ。パスワード再設定（`/auth/update-password`）時は例外的にアクセス許可。
- **ProtectedRoute**: ログイン必須。サイドバー等の共通UIを本Layoutに集約。

### E. スタイリング（MUI）
- **テーマの一元管理**: すべての色・サイズは `src/theme/theme.ts` を経由し、ハードコードを禁止する。
- **透明性の維持**: テーマの背景グラデーションを活かすため、白塗りを避け `transparent` 等を活用する。

## 4. セキュリティと共有
- **マルチテナント**: すべてのデータは `world_id` と `owner_id` で保護。
- **RLS (Row Level Security)**: DBレベルでのアクセス遮断を徹底。
- **QR共有機能**: `access_tickets` による期間限定の権限付与。

## 5. 開発ロードマップ

### フェーズ1：認証と基本UIの構築（完了）
1. 認証基盤（日本語確認メール・パスワードリセット）の完遂。
2. Layout構文によるアクセス制御の確立。
3. ダークで高級感のあるデザイン方針の決定。

### フェーズ2：コア機能の実装（現在進行中）
1. **基盤強化**: 絶対パスインポートの導入、定数管理の開始。
2. **DB永続化**: `worlds` テーブルのCRUD実装（`useWorlds` フック）。
3. **自動生成**: Entity作成時に「プロフィール用自己参照Connection」を自動生成。
4. **エディタ**: React Flowによるグラフ操作プロトタイプ作成。

### フェーズ3：高度な機能
1. `access_tickets` によるゲスト編集。
2. タイムライン可視化（'flow' 接続）。
